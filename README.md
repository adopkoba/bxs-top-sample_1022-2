# 文化シヤッターサービス コーポレートサイト（トップページ）

静的 HTML / CSS / JS のみ。ビルド・ライブラリ不要です。
**作業中**：ヘッダー・フッター・MV（固定 CTA・英字ループ・背景グラデ含む）・LP導線（シャッターメンテナンス）・全国対応ネットワーク・製品ラインナップ・お問い合わせフロー・コンテンツ一覧・文化シヤッターグループ・お知らせ・その他リンクまで、**トップページは全セクション実装済み**（PC はページ全体の高さが Figma と同じ 6453px）。SP は Figma に最新デザインがないため仮組み。

## ファイル構成

```
index.html          トップページ
css/base.css        全ページ共通（ベース・ヘッダー・メニュー・フッター・MV以降CTA・スクロールアニメーション）
css/top.css         トップページ専用（MV・重要なお知らせ・英字ループ・背景グラデ・FV-CTA）
js/main.js          全ページ共通（メニュー／ページ内スクロール／MVスライド／CTA切替／背景グラデ／スクロールアニメーション／ページトップ）
img/common/         全ページ共通の画像（ロゴ・キャラ・アイコン）
img/top/            トップページの画像（MV 写真は WebP）
_作業用/            Figma の書き出し・作業メモ（納品時は除く）
```

- HTML 内のパスは**相対パス**。WordPress 化の際は `img/` → `get_template_directory_uri()` に置換。CSS 内の `url(../img/…)` はそのままで動きます

## レスポンシブの仕組み（リキッド方式。2026-10-14 amenity 方式から変更）

社内テンプレート `_テンプレート/レスポンシブ_リキッド方式/CLAUDE.md` に準拠。

- **寸法は「Figma の px × 画面幅 ÷ デザイン幅」で常に比例**（PC 1366px／SP 390px 基準）
- 書き方：`calc(Figma の px ÷ 10 * var(--rem))`（例：24px → `calc(2.4 * var(--rem))`）。`--rem` は「Figma の 10px」を今の画面幅に換算した長さ（`css/base.css` 冒頭）
- px のままにするもの：1px の線、ごく小さい角丸

| 画面幅 | --rem | 見え方 |
|---|---|---|
| 1025px 以上 | `10 × 画面幅 ÷ 1366` | PC デザインをそのまま比例拡縮（1366px でデザインどおり） |
| 1024px 以下 | `10 × 画面幅 ÷ 390` | SP レイアウトを比例拡縮（390px でデザインどおり） |

- **1920px の上限**：`js/main.js` が `--vw` に画面幅（最大 1920px）を入れる。ヘッダー・フッター・固定 CTA は 1920px 相当で大きさが止まる。`#main` の中は `--vw: 100vw` に上書きしてあり、1920px を超えても比例し続ける。1920px を超えると body に `.is-capped`
- ブレークポイントは **1024 / 1025** の1つだけ（PC ⇔ SP）。`.pc` は 1024px 以下で非表示、`.sp` は 1025px 以上で非表示。hover は 1025px 以上のみ
- JS の定数（`js/main.js` 冒頭）：`SP_BREAKPOINT = 1024`、`VW_MAX = 1920`
- 旧方式（amenity）で入れていた 897〜1024px のタブレット用の調整（`.inner` の余白、ネットワーク・製品タブ・フローの zoom 0.91 など）は、PC がそのまま比例縮小するので削除した

## 動き（js/main.js）

| 動き | 対象 | 内容 |
|---|---|---|
| MV スライド | `.js-mvSlide img` | 4枚をクロスフェード（4秒表示・1.2秒フェード。Figma の HeroImage_Fade_Slideshow と同じ） |
| 固定 CTA の切替 | `#fvCta` / `#sideCta` | MV の下端が FV-CTA の下端より上に来たら、FV-CTA を消して MV 以降 CTA（右端タブ）を出す。タブは hover で左へスライド |
| MV 写真の固定 | `.mvSlide`（position: fixed） | 写真は画面に固定。英字ループと背景グラデがその上をスクロールしていく（Figma プロトタイプどおり） |
| 英字ループ | `.js-loopTrack` | 画面幅以上になるよう文を複製し、同じ組を2つつないで右→左へ無限ループ（大画面でも途切れない。文字の上端は帯の上端から 13px（Figma どおり。SP は上下中央）、文の間隔＝文字サイズは前回と同じ、不透明度 60%（Figma どおり）で、文字サイズだけ 2026-10-13 カンプの大きさ（PC 90px／SP 46px）。速さも前回と同じ見た目になるよう文1つあたり PC 67秒／SP 41秒） |
| 背景 | `.js-gradArea` / `.js-gradBg` | 固定写真の上に背景ぼかし 10px＋画面に貼り付く白レイヤー。白 80% → スクロールで徐々に白ベタ（ページ上端から 1305px かけて） |
| 丸い背景 | `.js-domeArea` / `.js-dome` | カンプの水色の背景（Figma「Frame 769」、#F3FAFD→#C8F0FD）。コンテンツ一覧〜グループ会社の後ろ。参考 alvamososaka.com の黄色い丸を計測して同じ動きに：円の上端はエリア上端から 400px 下（js の start＝40rem）から始まり、そこが画面下端に来ると、直径＝画面幅 74% の円が下から現れ、画面の高さ×2.2 のスクロールでイーズアウトしながら 3 倍に拡大＋中心が画面幅 48.8% 上へ。形は「円の上半分＋その下は全面」（clip-path: path() を JS で毎フレーム指定）。円はエリアの上へはみ出して、お問い合わせフローの後ろまで丸く広がる（.dome を CSS の --ext 分だけ上へ広げ、.domeArea を z-index: 0 にして前のセクションの文字より後ろに）。スクロール連動なので戻すと円に戻る |
| 左からふわっと | `.js-fade`（親に `.js-fadeGroup` で 0.12 秒ずつ時間差） | 画面に入ったら `.is-inview`。透明度＋左からの移動のみ（ぼかしなし）。全国対応ネットワークは文章→リード→エリアカードの順に出る。グループに `data-stagger`（秒）で間隔を変更、`data-trigger="group"` を付けると PC ではグループが画面に入った時点で左から順に開始（お問い合わせフローの STEP01〜04 は 0.25 秒間隔。SP は縦積みなので1枚ずつ画面に入ったときに表示） |
| 帯が伸びる | `.js-band` | Figma「Rectangle 4260」（全国対応ネットワークの青帯）。左から clip-path で伸びる（拡大縮小を使わないのでぼやけない） |
| エリア地図 | `.netArea li` / `.netMap .hl` | エリアカードに hover すると、地図の該当地域（`img/top/map_エリア.svg`）が重なって光り、カードの文字が青（0.3秒。PC のみ） |
| 製品タブ | `.js-tabs`（`[role=tab]` / `[role=tabpanel]`） | クリックで切替、0.25秒でフェード（Figma の Smart Animate 0.25s ease-out）。←→ キーでも切替 |
| コンテンツ一覧・グループ会社 | `.js-loopSlider` | 2026-10-13 カンプで同じ形のカルーセルに統一。カードを横に並べ（中央＋左右）、矢印で 0.5 秒移動、端はループ。下のバーで現在位置を表示。SP はスワイプ可。コンテンツ一覧は hover でカードが浮き文字が青。グループ会社は `data-auto="4000"` で 4 秒ごとに自動送り（hover・フォーカス・画面外・タブ非表示で停止） |
| 見出し | `.secTtl.js-secTtl` | Figma「h2-スクロールアニメーション」をもとに、青バーと紺バーが同時に伸び（0.4s）、縦線に縮んで文字が出る（0.6s）。上下のバーの時間差はユーザー指示でなくした |

見出しの HTML：

```html
<h2 class="secTtl js-secTtl"><span class="en">Network</span><span class="ja">全国対応ネットワーク</span></h2>
```
上の青バーの伸びる幅は `--bar-top-w`（既定 13.1rem）で見出しごとに変えられる。

## 未決・要確認事項

- **リンク先 URL**：ナビ・フッター・CTA はすべて `#`（仮）。外部リンク（文化シヤッター株式会社、オンラインショップ、カタログ）も URL 未確認
- **ハンバーガーメニューのデザイン**（現状は仮）
- **SP デザイン**（現状は PC からの仮組み）
- **MV 以降 CTA の縦位置**：Figma では MV 直下に置かれているため、固定時は画面上から 322px（Figma の位置関係）にした
- **MV 1枚目の写真**：白いキャッチコピーが明るい背景に重なり読みにくい（Figma どおり）
- 製品タブ 04「その他製品」の写真はダミー（Figma の説明に「04 サービスカタログ/ダミー」とある）。ボタンのリンク先（はるクール／ラクセット／シャッターガード／サービスカタログ）も未定
- コンテンツ一覧のアイコンは6枚とも工具（Figma のまま。カテゴリ別アイコン未支給）。会社情報の写真は元画像が 312×240 と小さく粗い → 差し替え推奨。リンク先も未定
- 文化シヤッターグループ：Figma に実在の内容があるのは 文化シヤッター／BXテンパル／BXゆとりフォーム の3社のみ。残り3枚（ドットは6個）は Figma のダミー（ゆとりフォームの複製）のまま → 掲載会社・説明文・リンク先の支給待ち。ロゴ画像も元が小さい（176〜280px幅）
- グループのスライダーは「中央のカード＝現在」で、1枚目（文化シヤッター）を中央に置いて始まる（Figma は中央がゆとりフォームの静止画）
- エリア別の拠点数（13/13/16/30/23/26/11/16）は Figma のホバー状態の値をそのまま固定で入れている
- 法人向け／個人向け CTA の色は MV 以降 CTA で両方 `#1db872`（Figma どおり）
